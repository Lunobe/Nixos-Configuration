# Installation

> [!NOTE]
> These steps assume NixOS is already manually installed on this hardware — disk partitioned, `@` and `@home` Btrfs subvolumes created, `nixos-install` run — and that you're booted into that fresh system with network access. This README only covers adopting this flake-based configuration on top of that base install.

1. Clone repository:
   > `git` isn't installed on a fresh system yet (it only gets installed via `programs.git` in `home.nix`, once step 4 runs) — use `nix shell` to get it temporarily.
   ```fish
   nix shell nixpkgs#git -c git clone https://github.com/Lunobe/Nixos-Configuration ~/Nixos-Configuration
   ```

2. Replace system configuration:
   ```fish
   sudo cp -r ~/Nixos-Configuration/* /etc/nixos/
   sudo chown -R lunobe:users /etc/nixos
   rm -rf ~/Nixos-Configuration
   ```
   > `hardware-configuration.nix` here is hardcoded to this machine's current filesystem UUIDs. Only reuse it if the underlying partitions/filesystems are unchanged (e.g. reinstalling without reformatting). If the disk was reformatted, the UUIDs generated by `nixos-generate-config` for the new filesystems will differ — keep that freshly generated file (or update the UUIDs in this one) instead of overwriting it blindly.
   >
   > The `chown` restores `lunobe` ownership right after the copy instead of waiting for the `systemd.tmpfiles.rules` entry in `configuration.nix` (`"Z /etc/nixos - lunobe users -"`) to fix it during step 4's `nixos-rebuild switch`.

3. Setup Btrfs subvolumes for snapshots:
   ```fish
   sudo mkdir -p /mnt/btrfs-root
   sudo mount -o subvolid=5 /dev/disk/by-uuid/<YOUR-BTRFS-UUID> /mnt/btrfs-root
   ```
   > Replace `<YOUR-BTRFS-UUID>` with your Btrfs partition UUID. Find it with: `lsblk -f`

   ```fish
   sudo rmdir /.snapshots /home/.snapshots 2>/dev/null || true

   sudo btrfs subvolume create /mnt/btrfs-root/@snapshots
   sudo btrfs subvolume create /mnt/btrfs-root/@home-snapshots

   sudo umount /mnt/btrfs-root
   sudo rmdir /mnt/btrfs-root
   ```

4. Build configuration and set password:
   ```fish
   sudo nixos-rebuild switch --flake /etc/nixos#nixos --extra-experimental-features "nix-command flakes"
   sudo passwd lunobe
   reboot
   ```

5. Initialize Git repository and connect to GitHub:
   ```fish
   cd /etc/nixos
   git init
   git add .
   git -c user.name="Lunobe" -c user.email="257240031+Lunobe@users.noreply.github.com" commit -m "initial"
   git remote add origin git@github.com:Lunobe/Nixos-Configuration.git
   ```
   > `/etc/nixos` is owned by `lunobe` (set by the `chown` in step 2, and kept that way afterwards by the `systemd.tmpfiles.rules` entry in `configuration.nix`), so these `git` commands run as your normal user — no `sudo`. Running them with `sudo` would leave `.git` root-owned and make the next `git remote add`/`push` fail with a permission error.

   ```fish
   ssh-keygen -t ed25519 -C "lunobe" -f ~/.ssh/id_ed25519
   ```
   > Add your SSH public key (`~/.ssh/id_ed25519.pub`) to GitHub before pushing:
   > **GitHub → Settings → SSH and GPG keys → New SSH key**

   ```fish
   git push -u origin main
   ```
